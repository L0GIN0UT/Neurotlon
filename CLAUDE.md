# Нейротлон

Система проведения мероприятия «Нейротлон BCI Samara-2027» в зале: участники с заранее созданными ID, жеребьёвка, пары, приём результатов со стендов и планшетов, расчёт очков, табло. Работает только в локальной сети, без интернета.

Перед работой прочитай:
- `docs/architecture.md` — схемы (источник истины, меняются через PR вместе с кодом);
- `docs/decisions.md` — принятые решения и открытые вопросы;
- `docs/roadmap.md` — этапы.

Открытые вопросы не решай сам — спроси.

## Структура монорепозитория

| Папка | Что | Стек |
|---|---|---|
| `server/` | API, база, расчёт, SSE | Python 3.12, FastAPI, SQLAlchemy + Alembic, SQLite (WAL) |
| `web/` | админка, регистрация, судья, PWA планшетов, табло | React + TypeScript (Vite) |
| `launcher/` | лаунчер стенда: вход по токену, QR/ID, запуск игры, офлайн-буфер | Python 3.12 |
| `bci-bridge/` | связь с BrainBit / Callibri, сигнал 0…1 для игр | Python 3.12 |
| `games/` | дартс, футбол, понг | Python 3.12, pygame-ce |
| `shared/` | контракты: OpenAPI, протокол мост → игра, формат результата и ID | JSON Schema |
| `deploy/` | установка на ПК админа | Docker Compose |
| `docs/` | документация и схемы Mermaid | — |

Инструменты: Python — `uv`, `pytest`, `ruff`, `mypy`; web — `npm`, `vitest`, `eslint`, `tsc`.

## Жёсткие правила

- **Никогда не указывай Claude или Anthropic как автора или соавтора**: никаких `Co-Authored-By: Claude`, `Generated with Claude Code`, ссылок на сессии Claude — ни в коммитах, ни в PR, ни в issues, ни в коде, ни в документации.
- Без интернета: никаких CDN и внешних сервисов во время работы системы; шрифты, библиотеки и иконки — локально.
- В базе нет ФИО и медданных. Категория «с ОВЗ / без» никогда не попадает в публичное табло, логи и тестовые фикстуры.
- Результат принимается идемпотентно по `session_id`.
- Итоги и рейтинг не хранятся — вычисляются из результатов секций.
- Журнал аудита только на добавление.
- Не пушить в `main` напрямую: ветка → PR.

## Субагенты и модели

Дорогая модель — только на планирование и проверку, код пишет более дешёвая.

| Агент | Модель | Когда |
|---|---|---|
| `planner`, `architect` | opus | план фичи, архитектурные решения |
| `security-reviewer` | opus | эндпоинты, аутентификация, токены станций, загрузки |
| `code-reviewer` | sonnet | после каждого изменения кода |
| `tdd-guide`, `build-error-resolver`, `refactor-cleaner`, `e2e-runner` | sonnet | написание кода, тесты, починка сборки |
| `doc-updater` | haiku | обновление документации |

Основная сессия — `opusplan` (Opus в режиме планирования, Sonnet при выполнении). Не задавай `CLAUDE_CODE_SUBAGENT_MODEL` — он перебивает модели агентов.

## Коммиты

Conventional Commits на английском: `type(scope): summary`, до 72 символов. Типы: `feat`, `fix`, `refactor`, `docs`, `test`, `chore`, `perf`, `ci`. Scope — папка (`server`, `web`, `launcher`, `bridge`, `games`, `shared`, `deploy`, `docs`). Тело — только если неочевидно «почему». Один коммит — одно логическое изменение.

## Pull request

Используй `.github/pull_request_template.md`. Коротко и по делу:
- **Что** — 1–3 пункта;
- **Зачем** — одно предложение, ссылка на этап роадмапа или issue;
- **Как проверить** — команды или шаги;
- **Риски** — только если есть (миграции, ломающие изменения), иначе раздел удалить.

Запрещено: пересказ диффа построчно, «улучшил читаемость», эмодзи, маркетинговые слова, упоминание Claude. Один PR — одна задача.
