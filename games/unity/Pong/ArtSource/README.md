# Исходники графики и звука понга

В `Assets/` лежат готовые модели, текстуры и звуки. Здесь — скрипты, которыми они сделаны, чтобы их можно было пересобрать и поправить. Blender 5.x, Python 3.

| Папка | Что делает | Запуск |
|---|---|---|
| `TableTennis/build_tt.py` | Стол (размеры ITTF), сетка, ракетка, мяч, текстуры дерева; экспорт FBX | `NT_PADDLE_REF=<фото> NT_OUT=<папка> blender -b --python build_tt.py` |
| `Arena/build_arena.py` | Турнирная арена: пол, борта с надписями, трибуны, толпа, рамка на стене; экспорт FBX | `NT_OUT=<папка> blender -b --python build_arena.py` |
| `Audio/make_sounds.py` | Звуки: удар, отскок, очко, золотой мяч, победа | `python -I make_sounds.py <папка>` |

Результат (FBX, PNG, WAV) копируется в `Assets/Art/` и `Assets/Audio/`.

## Происхождение

- **Стол, сетка, мяч, дерево ракетки** — моделируются скриптом, готовых чужих моделей нет.
- **Контур ракетки** снят с фотографии, которую предоставил владелец (`NT_PADDLE_REF`). Фото в репозиторий не входит; в модели остался только контур в сантиметрах.
- **Надписи на арене** — шрифт Inter (SIL Open Font License) из поставки Blender, вырезан в геометрию. Системные шрифты не используются.
- **Толпа** — силуэты зрителей, нарисованные скриптом (`build_arena.py`), чужих изображений нет.
- **Звуки** синтезированы скриптом.

Интернет для сборки не нужен.
