# Исходники графики и звука дартса

В `Assets/` лежат готовые модели, текстуры и звуки. Здесь — скрипты, которыми они сделаны, чтобы их можно было пересобрать и поправить. Blender 5.x, Python 3 (для текстуры дерева и звуков нужны `numpy` и `Pillow`).

| Папка | Что делает | Запуск |
|---|---|---|
| `Darts/build_darts.py` | Мишень (размеры PDC/WDF, булл крупнее стандартного, сизаль, проволока, пробковое кольцо) и дротик (вольфрамовый ствол с накаткой, латунные кольца, хвостовик, оперение «стандарт»); экспорт FBX и кадры для предпросмотра | `NT_OUT=<папка> blender -b --python build_darts.py` |
| `Darts/make_wood.py` | Текстура деревянной стены паба: доски, волокна, сучки | `python -I make_wood.py <файл.png>` |
| `Audio/make_sounds.py` | Звуки: бросок, попадание, центр, промах, конец игры | `python -I make_sounds.py <папка>` |

Результат (FBX, PNG, WAV) копируется в `Assets/Art/Darts/` и `Assets/Audio/`. Сцену из них собирает пункт меню `Neurotlon → Build Darts Scene`.

## Происхождение

- **Мишень и дротик** моделируются скриптом по стандартным размерам, готовых чужих моделей нет. Цифр вокруг мишени нет (решение владельца).
- **Текстура сизаля** (волокна и карта нормалей) и **дерево стены** — процедурные, рисуются скриптами, чужих изображений нет.
- **Арена из понга не используется:** сцена дартса — паб (дерево и тёплый свет).
- **Звуки** синтезированы скриптом.

Интернет для сборки не нужен.
