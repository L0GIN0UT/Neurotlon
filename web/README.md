# web

React + TypeScript (Vite). Страницы: планшет волонтёра `/tablet` (M5), админка `/admin`, судья `/judge` и табло `/board` (M6).

## Команды

```bash
npm install
npm run dev        # dev-сервер; /api проксируется на http://127.0.0.1:8000
npm run lint       # oxlint
npm run typecheck  # tsc -b
npm test           # vitest (jsdom)
npm run build      # tsc -b && vite build; кладёт в dist/ и sw.js
```

Для входа нужен запущенный `server/` и учётка волонтёра. Cookie сессии `Secure`:
на планшете адрес открывается по HTTPS (решение 7), на `localhost` работает и без него.

## Планшет волонтёра

Поток из `docs/architecture.md`, раздел 5:

1. **Участник**: QR камерой (`BarcodeDetector`, запасной вариант — `jsqr`, входит в сборку) или ручной ввод ID.
   ID приводится к виду `NT07` правилами из `shared/participant-code.md`. В понге нужны два игрока.
2. **Проверка**: `GET /participants/{code}/eligibility`. Проблемы показываются предупреждениями и не блокируют.
   Если участник не найден, продолжить нельзя; если нет связи, проверка пропускается.
3. **Ввод**: форма секции или «Не пройдено» с причиной. Таймер секции (из `GET /me/config`) только подсказка.
4. **Сводка** и кнопка «Записать».
5. **Записано**: «Отменить» 30 с (`POST /results/{session_id}/undo`), позже — «Запрос судье на исправление»
   (`POST /corrections`).

`session_id` создаётся при входе в шаг «Ввод» и не меняется при повторных отправках, поэтому повтор безопасен.

### Очки

Соответствие броска и элемента очкам лежит в одном файле `src/tablet/scoring/placeholder.ts`.
Это заглушка до утверждения методики подсчёта (решение 14): дартс — сумма бросков, футбол — выполненные
элементы плюс очки за точность, понг — очки вводятся как есть.

### Без связи

Если `POST /results` не дошёл (сеть, 401, 5xx), результат кладётся в IndexedDB (`neurotlon-tablet`) и
отправляется повторно каждые 5 с и при событии `online`. Счётчик очереди показан в шапке.
Ответы 200/201 убирают запись из очереди, 409/422 и другие 4xx переносят её в список «Ошибки»,
где волонтёр видит причину и может убрать запись.

Профиль и настройки секции копируются в `localStorage`, поэтому перезагрузка планшета без связи
не требует нового входа, пока жива сессия.

### PWA

`public/manifest.webmanifest` и `sw.js`. Service worker создаёт сборка (`sw-plugin.ts`): он кэширует
файлы оболочки приложения и отдаёт её при перезагрузке без сети. Запросы к `/api` не кэшируются.
Внешних адресов нет: библиотеки и иконки лежат в сборке.

Service worker регистрируется только в production-сборке. Сервер, раздающий `dist/`, должен
отдавать `index.html` для пути `/tablet` и `sw.js` из корня.

## Админка, судья, табло (M6)

Маршрутизатор — сравнение пути в `src/App.tsx` (`src/routes.ts`), вкладки внутри страниц — состояние.
Сервер, раздающий `dist/`, должен отдавать `index.html` для `/tablet`, `/admin`, `/judge`, `/board`.

- `/admin` (админ, суперпользователь): участники (создание ID, отметка о приходе с категорией и именем,
  отмена отметки, «Печать бейджей» открывает `badges.pdf`), жеребьёвка (варианты m, зерно, запуск после
  подтверждения, протокол с печатью через `window.print()`), станции (токен показан один раз, ротация,
  статус каждые 5 с), дисциплины (время игры и физической секции, очки за победу), пользователи
  (только суперпользователь), экспорт XLSX. Категория видна только в окне отметки и в протоколе жеребьёвки.
- `/judge` (судья, админ, суперпользователь): конфликты, запросы на исправление, поиск и правка результата
  (причина исправления обязательна, заблокированное правит только админ), «Зафиксировать итоги»
  с двойным подтверждением; при конфликтах и открытых запросах сервер отвечает 409, судья видит причины, а «Всё равно зафиксировать» есть только у админа. В понге правка — один выбор «Победитель».
- `/board` (без входа): табло на весь экран, поток `GET /api/v1/scoreboard/stream`; при закрытии потока
  он открывается заново с паузой 1…10 с, последние данные остаются на экране. Крупный шрифт в `vh`,
  системные шрифты, без прокрутки для 2 команд по 10 участников; двойной щелчок — полный экран.

## Структура

```
src/tablet/api.ts            типы по shared/openapi.yaml и клиент (credentials: include)
src/tablet/participantCode.ts  нормализация ID
src/tablet/payload.ts        сборка и проверка тела POST /results
src/tablet/offlineQueue.ts   очередь, повторы, список ошибок
src/tablet/idbStore.ts       хранилище очереди в IndexedDB
src/tablet/scoring/          заглушка подсчёта очков
src/tablet/components/       шаги потока
src/shared/                   HTTP-клиент, типы, тексты ошибок и вход, общие для страниц
src/staff/                    админка и судья (api.ts, вкладки в admin/ и judge/)
src/board/                    табло и подписка на SSE
src/test/                     общие помощники тестов (fake fetch, fake EventSource)
```

Категория участника (с ОВЗ / без) в интерфейсе и запросах не используется.
